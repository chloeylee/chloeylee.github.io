Kirby Reversi


Developed a hexagonal and square Reversi board game utilizing pair programming that used an aesthetically pleasing Kirby theme. In addition to implementing the standard rules of Reversi– including the essential gameplay mechanics and logic for moves, capturing, and turn-taking– we also programmed AI computer player mechanics that could utilize 1 or any combination of 4 strategies; capture max pieces, avoid next to corner, capture corner, and MiniMax.

Programmed using Java 11 and created thorough tests using JUnit 4.
